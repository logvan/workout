# Сервер «Дневник героя»

Аккаунты по логину и паролю, у каждого пользователя свои данные. Внутри — PocketBase (одна программа: база данных, вход, правила доступа, админка).

## Что нужно
- Сервер на Linux (Ubuntu/Debian), где уже есть nginx.
- Поддомен, направленный на этот сервер (A-запись), например `api.ваш-домен.ru`.
- Доступ по SSH с правами sudo.

Места занимает мало: программа ~40 МБ, память ~50–100 МБ, данные ~1–3 МБ на человека в год.

## Установка (один раз, ~5 минут)
Зайдите на сервер по SSH и выполните (подставьте свой поддомен и почту):

```bash
curl -fsSL https://github.com/logvan/workout/archive/refs/heads/main.tar.gz | tar xz
cd workout-main/server
sudo bash install.sh api.ваш-домен.ru вы@почта.ru
```

Скрипт сам:
1. создаст отдельного системного пользователя `hero` и папку `/opt/hero`;
2. скачает PocketBase и создаст базу (таблицы и правила доступа);
3. создаст администратора (пароль: `sudo cat /opt/hero/.admin_created`);
4. включит автозапуск (`systemctl status hero`);
5. добавит в nginx отдельный сайт для поддомена и получит сертификат HTTPS (если установлен certbot);
6. включит ночные копии базы в `/opt/hero/backups` (храним 14 дней).

Другие сайты на сервере не затрагиваются.

## Проверка
```bash
curl https://api.ваш-домен.ru/api/hero/health
```
Должно ответить `{"ok":true,"app":"dnevnik-geroya",...}`.

Админка: `https://api.ваш-домен.ru/_/` — там видны пользователи и данные, можно сбросить пароль пользователю.

## Обновление
Те же три команды установки — скрипт обновит код сервера и применит новые изменения базы, данные сохранятся.

## Полезное
- Логи: `sudo journalctl -u hero -n 100`
- Перезапуск: `sudo systemctl restart hero`
- Копия базы вручную: `sudo -u hero /opt/hero/backup.sh`
- Сделать продукты пользователя общими для всех: в админке войдите как администратор и вызовите `POST /api/hero/admin/promote {"username":"логин"}`.

## Команды iPhone
У каждого пользователя свой ключ: в приложении «Настройки → Аккаунт → Команды iPhone». В команде «Дневник» действие «Получить содержимое URL»: адрес `https://api.ваш-домен.ru/api/hero/shortcut`, метод POST, JSON: `secret` — ключ, `text` — «Ввод команды» (для веса и воды добавить `type` = `weight` / `water`).
